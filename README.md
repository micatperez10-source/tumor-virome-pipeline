# Tumor Virome & Variant Pipeline
Pipeline automatizado en Nextflow para el análisis de secuencias de la línea celular MCF-7.

## Características
- Descarga automatizada desde NCBI SRA.
- Control de calidad con FastQC.
- Arquitectura basada en contenedores Docker (reproducibilidad total).
- Optimizado para Apple Silicon (M1/M2/M3).

## Requisitos
- Nextflow
- Docker Desktop
